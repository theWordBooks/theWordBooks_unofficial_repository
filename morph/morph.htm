Morphology Helper Definitions

Add guided morphology choices to the Inline Helper and Morphology Builder in theWord 7.6.1.1611 or newer.

General morphology helpers

These encrypted .morphx definitions can be used without a purchased-module unlock:

  • BSB — Berean Standard Bible morphology
  • LXX-PMAC — Septuagint parsing morphology
  • RMAC — Robinson Greek morphology

Helpers for purchased Bibles

These test packages work only when their matching Bible is validly unlocked:

  • BHS5/ETCBC — for the BHS5/ETCBC Bible
  • WHM — Westminster Hebrew Morphology

It is safe for other users to install them. theWord simply leaves a protected definition inactive when the corresponding Bible is unavailable. Installing a helper does not unlock or include the purchased Bible.

Language support: Each morphology system now has one canonical structural definition. theWord translates its shared labels through the normal program language files, while retaining English fallback labels.

For earlier testers: Plain .morph files are no longer supported. Install the replacement .morphx packages shown here. The protected BHS5/ETCBC and WHM helpers are temporarily available in this test repository; final releases will include them with their corresponding Bible installers.
